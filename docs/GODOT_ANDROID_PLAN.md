# Godot 4 Android implementation plan

## Current baseline

The project is an early greybox prototype:
- Godot 4.4 project configuration with Compatibility renderer.
- Procedural blockout streets and buildings generated by `scripts/world.gd`.
- A capsule-based third-person player and camera in `scripts/player.gd`.
- A custom touch HUD with virtual movement stick, sprint, jump and camera drag in `scripts/mobile_hud.gd`.

There is no detailed city map, vehicle implementation, networking, account system, database, economy or APK release yet.

## Milestone 1 — stable Android prototype

- Keep the project opening in Godot 4.4.
- Verify scene startup and eliminate parser/runtime errors.
- Make movement camera-relative.
- Check multi-touch behavior, screen aspect ratios, safe areas and touch target sizes.
- Add a pause/settings overlay and basic input feedback.
- Build a debug ARM64 APK and test it on a physical Android device.

Acceptance criteria:
- Main scene starts without errors.
- Player can move, rotate camera, sprint and jump using touch.
- Controls remain reachable on supported Android aspect ratios.
- Debug APK installs and launches on a physical ARM64 Android device.

## Milestone 2 — Chișinău district blockout

- Replace generic blocks with original modular low-poly buildings.
- Create a compact, navigable district with sidewalks, intersections and landmarks inspired by Chișinău.
- Add collision, navigation and occlusion/performance checks.
- Keep original geometry and assets; do not import copyrighted GTA map data.

## Milestone 3 — vehicle prototype

- Add one original low-poly vehicle.
- Implement enter/exit, acceleration, braking, steering, camera follow and collision.
- Keep vehicle state deterministic enough for later server validation.
- Test touch driving controls and low-end Android performance.

## Milestone 4 — multiplayer foundation

- Choose and pin a maintained networking approach after a separate license/security review.
- Use a dedicated headless server build.
- Server validates identity, movement bounds, vehicle state and all gameplay transactions.
- Add reconnect handling and persistence only after server authority is established.

## Milestone 5 — serious roleplay systems

- Account and character identity.
- Jobs and public services.
- MDL economy, inventory and shops.
- Vehicles, ownership and property.
- Police, EMS, moderation, audit logs and anti-abuse controls.
- Romanian, Russian, Italian and English localization.

## Constraints

- No Unity license or Unity editor is required for this Godot branch.
- Cloud APK builds still require a configured Godot export toolchain, Android SDK/JDK and a working CI provider.
- The current GitHub Actions account billing lock may block GitHub-hosted Actions independently of the engine.
- No APK or device test is claimed until a real build artifact is produced and tested.
- Do not include Rockstar assets or other content without redistribution rights.
